# Mobile Phone Sales Data Analysis – EDA

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a Mobile Phone Sales dataset using Python. The objective is to clean, analyze, and visualize the data to identify meaningful patterns and insights.

## Tools & Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Activities
- Data Loading and Understanding
- Data Cleaning and Preprocessing
- Handling Missing Values
- Removing Duplicate Records
- Outlier Detection and Treatment
- Exploratory Data Analysis
- Data Visualization
- Analyzing Brand-wise Sales and Pricing Patterns

## Key Analysis Areas
- Brand-wise Mobile Phone Sales
- Price Distribution
- RAM and Storage Analysis
- Battery and Camera Specifications
- Customer Ratings
- Sales Trends and Patterns

## Project Files
- Jupyter Notebook: Complete EDA implementation
- CSV Dataset: Raw mobile phone sales data

## Objective
To gain practical experience in data analysis, data cleaning, statistical exploration, and visualization using Python libraries.
